# Fuki / 吹替 visual assets

The approved visual source is the original raster design in `fuki-original-design.png`.

| File | Purpose |
| --- | --- |
| `fuki-original-design.png` | Untouched original design board and source of truth |
| `fuki-mark.png` | Square application-mark crop from the original design |
| `fuki-logo.png` | Horizontal `Fuki 吹替` lockup crop from the original design |
| `fuki-mark-{size}.png` | Directly resized application marks for common UI sizes |

There is deliberately no vector master. The production PNGs are crops and size exports of the original design only; do not redraw, trace, vectorize, or reinterpret the mark without explicit approval.

Brand colors and letterforms should be sampled from the original raster artwork rather than reconstructed from approximate values or substitute fonts.
